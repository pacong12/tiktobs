Quick Start Guide

  1. Buka Aplikasi: Jalankan file TikTokOBS.exe. Aplikasi akan secara otomatis membuka web dashboard di browser Anda (http://127.0.0.1:8000).
  2. Set API Key: Pergi ke menu Settings dan masukkan EulerStream Sign API Key Anda.
  3. Hubungkan TikTok Live: Masukkan Username TikTok Anda di Live Dashboard lalu klik Connect.
  4. Buat Polling: Buka Poll Admin, tentukan nama kandidat & gift boost, lalu klik Start Live Poll.

Aturan Voting & Fast-Track Gift

Comment Voting (Komentar Penonton)

  • Penonton dapat memilih dengan mengetikkan nama kandidat di kolom komentar live (misal: Alice atau pilih Alice ya).
  • Sistem mendukung Substring Matching cerdas yang mengenali nama kandidat di dalam kalimat.
  • Jika komentar mengandung lebih dari 1 nama kandidat sekaligus (misal: Alice vs Bob), sistem akan otomatis membatalkan vote tersebut demi mencegah pemungutan ganda ambigu.
  • 1 penonton hanya memiliki 1 hak suara komentar per sesi polling.

Gift Boost Voting (Jalur Cepat Gift)

  • Anda dapat memetakan Gift tertentu ke kandidat (misal: Gift Rose = Candidate Alice).
  • Setiap Gift yang dikirim memberikan Poin Tambahan sesuai dengan jumlah Diamond dari Gift tersebut (misal: 15 Diamond = +15 Votes).
  • Gift Boost **TIDAK TERBATAS** oleh pembatasan 1 user (penonton bisa mengirim gift berulang kali untuk memboster suara kandidat favoritnya).

Kustomisasi Suara Alert

Anda dapat mengupload efek suara custom Anda sendiri (file .mp3 atau .wav) melalui menu Poll Admin pada bagian Gift Alert Sound Settings.

  • Suara yang di-upload akan diolah menggunakan Web Audio API Engine (0ms latency & mendukung tumpukan suara sekaligus tanpa saling memotong).
  • Gunakan tombol Test Play untuk mendengarkan pratinjau suara secara langsung.
