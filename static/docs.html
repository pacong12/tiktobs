🚀 Quick Start (5 menit)

  1. Jalankan aplikasi — buka TikTokOBS.exe. Dashboard otomatis terbuka di browser pada alamat http://127.0.0.1:8000.
  2. Sambungkan ke live Anda — di 🏠 Live Dashboard, ketik username TikTok yang sedang live, klik Connect.
  3. Buat polling — buka 🗳️ Poll Admin, isi judul + minimal 2 kandidat, klik 🚀 Mulai Voting Live.
  4. Tampilkan di OBS — tambahkan URL overlay sebagai Browser Source (lihat Memasang Overlay di OBS).
  5. Selesai! Penonton mulai vote dengan komentar angka atau gift, dan hasilnya langsung terlihat di OBS.
💡 Belum live / ingin coba dulu? Lihat bagian 🧪 Simulasi — Anda bisa menguji semua fitur tanpa harus live beneran.

🔴 Menyambungkan ke TikTok LIVE

  1. Buka 🏠 Live Dashboard.
  2. Ketik username TikTok yang sedang live (tanpa @ juga boleh), lalu klik Connect.
  3. Tunggu indikator berubah menjadi 🟢 connected — artinya semua komentar, gift, like, dan follow mulai masuk.

Di dashboard ini Anda bisa memantau:

  • Penghitung real-time: komentar, gift, like, follow, share, viewer.
  • Daftar event terbaru (klik salah satu baris untuk melihat detailnya).
  • Leaderboard pengirim gift terbanyak sesi ini.
💡 Koneksi terputus? Aplikasi otomatis menyambung ulang. Tombol Disconnect hanya perlu dipakai saat Anda selesai.
⚠️ Pastikan streamer benar-benar sedang live. Jika tidak, status akan menjadi failed.

🗳️ Membuat & Menjalankan Polling

Semua pengaturan polling ada di 🗳️ Poll Admin.

Mempersiapkan polling

  • Judul — pertanyaan untuk penonton, mis. Siapa karakter favoritmu?
  • Nama ronde (opsional) — mis. Ronde 1 atau Babak Final. Ikut tampil di overlay.
  • Durasi (opsional) — dalam detik. Kosongkan jika ingin menghentikan manual. Saat waktu habis, polling otomatis berhenti dan hasilnya tersimpan.
  • Kandidat — minimal 2. Isi nama; foto dan gift boost opsional:
    • Foto: URL gambar kandidat (tampil di overlay voting).
    • Gift boost: nama gift khusus untuk kandidat itu, mis. Rose untuk Alice. Setiap gift Rose yang masuk otomatis jadi vote untuk Alice (1 diamond = 1 vote).
  • Hitung riwayat sebelum polling — centang bila komentar & gift yang sudah masuk sebelum tombol Start juga ingin dihitung.

Menjalankan & menghentikan

  • Klik 🚀 Mulai Voting Live — polling aktif, semua overlay langsung menampilkan kartu kandidat.
  • Selama berjalan, panel status menunjukkan countdown, total vote, dan hasil sementara.
  • Klik 🛑 Hentikan & Simpan Ronde untuk mengakhiri — pemenang diumumkan di overlay dan hasil diarsipkan.
💡 Polling aman dari restart: kalau aplikasi tidak sengaja tertutup saat polling berjalan, cukup buka lagi — polling dilanjutkan dengan vote yang utuh.
⚠️ Satu gift hanya boleh ditugaskan ke satu kandidat. Jika dua kandidat memakai gift yang sama, aplikasi menolak memulai polling.

💬 Cara Penonton Memberi Vote

Umumkan dua cara vote ini ke penonton Anda:

1️⃣ Vote lewat komentar

Penonton cukup mengetik nomor urut atau nama kandidat di kolom komentar. Semua format ini dihitung:

01  ·  1  ·  #1  → vote untuk kandidat no. 1
Alice  ·  pilih Alice ya!  → vote untuk kandidat bernama Alice
  • Setiap komentar yang cocok = 1 vote. Boleh vote berkali-kali, tidak ada batasan.
  • Komentar yang memuat dua kandidat sekaligus (mis. Alice vs Bob) dianggap ambigu dan tidak dihitung.
  • Komentar biasa (sapaan, candaan) aman — tidak memengaruhi hasil.

2️⃣ Vote lewat gift

  • Gift yang ditugaskan ke kandidat (gift boost) langsung dihitung: 1 diamond = 1 vote. Contoh: Rose harganya 1 diamond → Rose ×99 = 99 vote.
  • Gift lain (Rocket, Universe, dll.) tetap bisa jadi vote jika pengirimnya sudah komentar vote sebelumnya — penjelasannya di bagian berikutnya 👇

🎁 Gift yang Tidak Cocok Kandidat

Pertanyaan paling umum: "Kalau penonton kirim Rocket, vote-nya masuk ke mana?"

Aplikasi memakai aturan cerdas yang selalu aktif selama polling berjalan:

SituasiYang terjadi
🎯 Gift cocok kandidat
(gift boost)		Langsung dihitung: 1 diamond = 1 vote.
🚀 Gift lain + penonton pernah komentar vote di polling iniDihitung ke kandidat yang dia pilih di komentar terakhirnya (1 diamond = 1 vote), dengan tanda "via komentar" di overlay.
❌ Gift lain + belum pernah komentar voteTidak dihitung. Penonton diberi pesan edukasi di layar: komentar dulu angka/nama kandidat, baru kirim gift.

Contoh alurnya

Budi komentar "02"   → vote untuk kandidat no. 2 tercatat
Budi kirim Rocket (5000 💎) → +5000 vote untuk kandidat no. 2 🎉
  • Yang dipakai adalah komentar vote terakhir — kalau Budi kemudian komentar "01", gift berikutnya masuk ke kandidat no. 1.
  • Komentar iseng (wkwkwk, halo kak) tidak mengubah pilihan terakhir.
  • Di setiap ronde baru, pilihan lama otomatis direset — penonton harus komentar lagi.

Feedback di layar (transparan)

  • Overlay vote memunculkan toast 🚀 Rocket +5000 ➤ Bob · via komentar "02".
  • Alert gift menampilkan kartu merah +0 VOTES untuk gift yang tidak dihitung, lengkap dengan panduan cara vote yang benar.
  • Gift Bubbles menampilkan bubble merah dengan foto profil pengirim + tanda ❌.
  • Poll Admin mendapat notifikasi (toast) yang sama, jadi Anda selalu tahu apa yang terjadi.
💡 Saran untuk penonton (ucapkan saat live): "Komentar dulu nomor kandidat, baru kirim gift apa saja — pasti dihitung!"

🎵 Suara Alert

Atur di 🗳️ Poll Admin bagian Sound Settings:

  1. Klik 📤 Upload untuk menambahkan file suara Anda (.mp3 / .wav / .ogg / .m4a, maks 25 MB).
  2. Pilih suara untuk Gift Alert dan Vote Alert dari dropdown (biarkan kosong untuk chime bawaan).
  3. Atur volume (0–100%) dan tekan 🔊 Test untuk mencoba.

Perubahan langsung berlaku di semua overlay OBS yang sedang terbuka — tanpa perlu refresh.

📜 Riwayat Ronde & Ekspor CSV

  • Setiap polling yang selesai otomatis masuk Riwayat Ronde di Poll Admin (judul, waktu, durasi, total vote, hasil per kandidat).
  • Tombol 📥 Ekspor CSV mengunduh semua ronde sebagai file spreadsheet (satu baris per kandidat) — siap dibuka di Excel / Google Sheets.
  • Ronde bisa dihapus satu per satu atau sekaligus.

📢 Running Text (Ticker)

  • Buka ⚙️ Settings → bagian Running Text.
  • Tulis pesan (satu baris per pesan, bisa banyak), atur kecepatan, arah, dan teks pemisah, lalu Simpan.
  • Overlay ticker di OBS langsung berubah tanpa refresh.
Contoh: "Ketik angka kandidat untuk vote! 🗳️ ✦ Kirim gift = vote (komentar dulu) 🎁 ✦ Follow untuk dukungan ❤️"

🔐 API Key & Token

TikTok Sign API Key (EulerStream)

Opsional. Jika Anda berlangganan layanan cloud EulerStream, masukkan API key di Settings lalu restart aplikasi. Tanpa key, aplikasi tetap berfungsi penuh memakai koneksi lokal.

API Access Token

Untuk penggunaan pribadi di komputer sendiri, bagian ini bisa diabaikan. Jika server ingin diproteksi: set variabel TIKTOBS_API_TOKEN di file .env, lalu simpan token di halaman Settings — semua halaman & overlay akan otomatis memakainya.

🧪 Coba-coba Tanpa Live (Simulasi)

Ingin melihat overlay bekerja sebelum live beneran? Aktifkan mode simulasi dengan menjalankan aplikasi lewat variabel lingkungan:

TIKTOBS_TEST_ENDPOINTS=1 python run_app.py

Setelah itu, di bagian bawah Poll Admin muncul panel Test Simulation dengan tombol:

  • 💬 Test Comment Vote — pura-pura ada penonton komentar angka kandidat.
  • 🎁 Test Gift Boost — pura-pura ada gift yang cocok kandidat.
  • 💎 Test Regular Gift — pura-pura ada gift umum (menguji jalur fallback & pesan "+0 VOTES").
  • 🎆 Test Gift Combo — pura-pura gift streak panjang (mis. Rose ×50) sekaligus.

Alur uji lengkap yang disarankan: mulai polling → kirim Test Comment Vote dari user X → kirim Test Regular Gift → lihat vote X melonjak dengan keterangan via komentar di overlay. 🎉
